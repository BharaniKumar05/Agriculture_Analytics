🌾 Agriculture Analytics Platform
Project Description

Agriculture Analytics Platform is an end-to-end data analytics project designed to analyze agricultural data and generate meaningful insights from crop production, rainfall, and fertilizer datasets.

The project uses Python for data processing, PostgreSQL for data storage and SQL analysis, and Power BI for interactive dashboards. It provides insights into crop production trends, rainfall patterns, fertilizer recommendations, and state/district-level agricultural performance.

🔧 Technologies Used
Python – Data cleaning and preprocessing
PostgreSQL – Database management
SQL – Data analysis and querying
Power Query – Data transformation
Power BI – Interactive dashboards and visualization
DAX – Measures and calculations
Streamlit – Web-based analytics application
Pandas – Data manipulation
Plotly – Interactive visualization

🗄️ Database

PostgreSQL contains three main tables:

crop_production
rainfall
fertilizer

SQL queries were developed and tested using pgAdmin for aggregation, filtering, ranking, grouping, and analytical analysis.

The main objective is to transform raw agricultural data into clear, interactive, and decision-oriented insights that can help understand crop production, rainfall patterns, and fertilizer requirements.
